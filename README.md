# Sales Order Reporting System (SAP ABAP)

## 📌 Overview
Developed a custom ALV report using VBAK and VBAP tables.

## 🚀 Features
- Selection screen with filters
- INNER JOIN between VBAK & VBAP
- ALV Grid Display
- Sorting & Subtotals
- Interactive Drill-down

## 🛠️ Technologies
- SAP ABAP
- ALV (REUSE_ALV_GRID_DISPLAY)
- Open SQL

## 🎯 Learning Outcome
Hands-on experience with real-time reporting and ALV.
